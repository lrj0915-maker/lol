LOL 战绩助手启动方式

1. 双击 `LOL战绩助手.cmd`
   - 如果已经打包过，会直接启动 `dist\LOL战绩助手\LOL战绩助手.exe`
   - 如果还没打包，会直接用 Python 启动 `backend\main.py`

2. 如果你想固定桌面入口
   - 右键 `LOL战绩助手.cmd`
   - 发送到 -> 桌面快捷方式

3. 如果你想把它做成真正的桌面程序
   - 需要先打包生成 exe
   - 当前项目的 PyInstaller 配置已经在 `build_config\lol-assistant.spec`

注意
- 现在这个入口是最省事的方式，不需要额外图标也能从桌面直接启动。
- 如果你之后想要桌面快捷方式图标，我可以继续帮你补一个 `.ico` 并接入打包配置。
